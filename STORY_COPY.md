# A Little Bit of Everything — the Story Behind the Portfolio

## The hero

**A little bit of everything.** Part engineer. Part storyteller. Hopelessly curious.

I build games, automate the boring stuff, break cloud deployments, make strange things in Blender, chase good light, and learn something from every detour. This is a home for all of it.

## The central thought

I started with a simple obsession: “What happens if I try to build this?” That question took me from game mechanics to real-time servers, from websites to cloud infrastructure, and from automation to the possibility of AI systems that actually learn through work.

Some things shipped. Some broke spectacularly. Some are still sketches and experiments. I’m proud of the learning, not just the green checkmarks.

## The chapters

1. **The spark:** PixelMania and HireFlow, where building features turned into understanding shared state, workflow, identity and automation.
2. **The real world:** MoodBuds, Awaaz, Automex and a Linux recovery taught infrastructure, network boundaries, delivery, logs and incident response.
3. **The all-nighter:** Dishari was a multilingual document-assistance demo built under hackathon pressure. It did not advance to the next round. It still shipped, and became a source of technical and human lessons.
4. **What's next:** Wayne Citadel security reasoning and TenseBots autonomous DevSecOps agents. A working local prototype is not the same as proven self-improving model weights.

## What the failures taught

- Investigate npm errors before asserting a root cause.
- A Compose workflow depends on correctly installed, executable Docker plugins.
- Trace API calls from the sending container's point of view.
- A backup must be verifiable and usable, not merely present.
- Preserve the process lessons alongside the code fixes.

## The person, not only the programmer

I like being a beginner. Mountains, long walks, open skies, quiet mornings, photography, music edits, fitness, Blender experiments and writing are as much a part of me as server logs. I want to keep making things and keep noticing the world around me.

## Closing

I'm a third-year AI & ML undergraduate, not a finished product. I'd rather be curious, try, fail, learn, and build again than stay comfortably in one lane.

**Got a wild idea? Let's make something.**
